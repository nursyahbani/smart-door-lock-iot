# Smart Door Lock IoT

Smart Door Lock berbasis Internet of Things (IoT) yang menggunakan ESP8266, RFID RC522, Relay, dan Solenoid Door Lock. Sistem dilengkapi dashboard web berbasis PHP dan MySQL untuk mengelola akses pintu secara jarak jauh.

## Features
- RFID Authentication
- Web Dashboard Control
- User Login & Registration
- Database Access Management
- Real-Time Door Control
- IoT Monitoring

## Technologies
- ESP8266 NodeMCU
- RFID RC522
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Project Documentation
Smart Door Lock dikembangkan sebagai proyek Internet of Things untuk meningkatkan keamanan akses ruangan menggunakan autentikasi RFID dan kontrol berbasis web.
